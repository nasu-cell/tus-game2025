# tus-game2025 — マルチプレイヤータンク対戦ゲーム

授業の一環として開発した、最大4人同時プレイ対応のタンク対戦アクションゲームです。

---

## ゲーム概要

プレイヤーはタンクを操作し、マップ上のほかのタンクを倒すことを目的とします。  
設定ラウンド数を先に制したプレイヤーがゲームの勝者となります。

- **プレイ人数**: 1〜4人（CPU対戦・ローカルマルチプレイ対応）
- **ゲームモード**: ラウンド制・最後の1台が残ったプレイヤーの勝利
- **ステージ**: 3種類（デザート / ジャングル / 月面）

## 実装詳細

### 砲塔の独立制御・TPSカメラモード
オリジナルの「Tanks!」は車体と砲塔が一体だったところを、砲塔を独立して回転できるよう拡張しました。  
あわせてサードパーソン視点のカメラを実装し、砲塔の向きを軸に追従するTPSモードを追加しています。

### 地雷システム
砲弾とは独立した弾薬として対戦車地雷を追加しました。設置から2秒後に起動し、タンクが接近すると爆発します。  
砲弾・地雷それぞれにカートリッジとストック数の概念を持たせ、弾薬管理の戦略性を高めています。

### ワームホール（テレポーター）
マップ上に設置したワームホールへ進入するとランダムな出口へテレポートします。  
通過中の戦車・砲弾・地雷それぞれの挙動を仕様として定義し実装しました。通過中の戦車には点滅演出付きの無敵状態を付与しています。

### 画面遷移・HUD
タイトル → ホーム（プレイヤー設定）→ ゲームの画面遷移と、HPゲージ・ラウンド勝利数・砲弾飛距離ゲージを含むHUDを実装しました。

### ネットワーク（実装中）
Unity Netcode for GameObjectsを用いたオンラインマルチプレイを実装中です。  
現時点ではロビー画面のReadyボタンと通信基盤の構築まで完了しています。

## 操作方法（キーボード / ゲームパッド）

| 操作 | キーボード（P1例） | ゲームパッド |
